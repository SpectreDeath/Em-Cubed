## Invariants & Guardrails

- [ ] **BFO Consistency**: All induced triples must be subsumed under valid BFO upper classes.
- [ ] **Deterministic Convergence**: Synthesized directives must measurably reduce retry counts.
- [ ] **Bounded Induction Depth**: Never induce more than 50 assertions per evolution run without human approval.
