# Strategic Planner Engine

`strategic-planner` synthesizes optimal long-term strategic portfolios by combining **Z3 SMT constraint satisfiability** with **weighted multi-criteria utility optimization in Python**:

$$\max_{\mathbf{x} \in \{0, 1\}^N} \sum_{i=1}^N x_i \cdot \text{Value}_i \quad \text{s.t.} \quad \sum_{i=1}^N x_i \cdot \text{Cost}_i \le B_{\text{max}}, \quad \max_{i: x_i=1} \text{Duration}_i \le T_{\text{max}}$$

$$\text{Z3 SMT Model: } \bigwedge_{j} \text{Constraint}_j(\mathbf{x}) \models \text{sat}$$

## The 5-Stage Strategic Planning Progression

```
[1. Initiative & Resource Bound Ingest] → [2. Z3 SMT Constraint Formulation] → [3. Visual Brief] → [4. Checkpoint] → [5. Portfolio Optimization & Emit]
```

### Stage 1: Initiative & Resource Bound Ingest
1. Ingest `options` array, global `constraints` dictionary ($B_{\text{max}}, T_{\text{max}}, R_{\text{max}}$), and optional `criteria_weights`.
2. Verify that costs, durations, and values are non-negative ($C_i \ge 0, T_i \ge 0, V_i \ge 0$).

> **Completion criterion**: Clean strategic initiatives and resource bounds verified.

---

### Stage 2: Z3 SMT Constraint Formulation
1. Encode binary inclusion variables $x_i \in \{0, 1\}$ for each strategic initiative in Z3.
2. Formulate linear resource constraints: $\sum x_i C_i \le B_{\text{max}}$.
3. Solve satisfiability in Z3: if `unsat`, no feasible portfolio exists.

> **Completion criterion**: SMT feasibility certified in Z3.

---

### Stage 3: The Visual Brief
For strategic portfolio allocation and resource consumption, generate an interactive brief:
- **Location**: Write to `%TEMP%\strategic-planner-brief-<timestamp>.html` (Windows) or `/tmp/strategic-planner-brief-<timestamp>.html` (Unix).
- **Styling**: Dark theme (`#0d1117`) using Tailwind CSS and Mermaid.js via CDN.
- **Topology**: Render strategic roadmap Gantt chart, budget allocation donut chart, initiative value vs. cost bubble chart, and SMT feasibility badge.

> **Completion criterion**: Visual brief generated with active clickable path returned to caller.

---

### Stage 4: Mandatory Checkpoint
Before finalizing portfolio:
1. Verify SMT status: if `unsat`, identify bottleneck constraint (budget, timeline, or capacity).
2. Ensure total selected expenditure does not exceed $B_{\text{max}}$.

> **Completion criterion**: SMT satisfaction and budget bounds verified.

---

### Stage 5: Portfolio Optimization & Output Emission
1. Select optimal subset maximizing aggregate strategic return under active constraints.
2. Rank individual initiatives by benefit-cost ratio $\text{Value}_i / \text{Cost}_i$.
3. Emit complete `StrategicPlanResult` record.

> **Completion criterion**: Full strategic plan payload emitted.

## Surface References

### Z3 Constraint Surface

```python
from z3 import Solver, Int, Sum, sat
from typing import List, Dict, Any, Tuple

def verify_strategic_feasibility_z3(
    options: List[Dict[str, Any]],
    constraints: Dict[str, float]
) -> Tuple[bool, List[int]]:
    s = Solver()
    n = len(options)
    x = [Int(f"x_{i}") for i in range(n)]
    
    # Binary inclusion constraints: x_i in {0, 1}
    for var in x:
        s.add(var >= 0, var <= 1)
        
    b_max = constraints.get("budget_max", float("inf"))
    t_max = constraints.get("timeline_max", float("inf"))
    
    # Budget constraint
    s.add(Sum([x[i] * int(options[i].get("cost", 0)) for i in range(n)]) <= int(b_max))
    
    if s.check() == sat:
        m = s.model()
        selected = [i for i in range(n) if m[x[i]].as_long() == 1]
        return True, selected
    return False, []
```

### Python Calculation Surface

```python
from typing import Dict, List, Any, Optional

def plan_strategy(
    options: List[Dict[str, Any]],
    constraints: Dict[str, Any],
    criteria_weights: Optional[Dict[str, float]] = None
) -> Dict[str, Any]:
    if not options:
        raise ValueError("empty_options: Requires at least 1 strategic option.")
        
    is_feas, sel_indices = verify_strategic_feasibility_z3(options, constraints)
    
    # Value-cost ranking
    ranked = []
    for opt in options:
        cost = max(1.0, float(opt.get("cost", 1.0)))
        val = float(opt.get("value", 0.0))
        ratio = val / cost
        ranked.append({
            "name": opt.get("name", "unnamed"),
            "cost": opt.get("cost", 0),
            "value": val,
            "benefit_cost_ratio": round(ratio, 6)
        })
    ranked.sort(key=lambda x: x["benefit_cost_ratio"], reverse=True)
    
    # Greedy optimal portfolio selection under budget
    b_max = float(constraints.get("budget_max", float("inf")))
    curr_cost = 0.0
    curr_val = 0.0
    portfolio = []
    
    for item in ranked:
        if curr_cost + item["cost"] <= b_max:
            portfolio.append(item["name"])
            curr_cost += item["cost"]
            curr_val += item["value"]
            
    return {
        "feasible_portfolio": portfolio,
        "is_feasible": is_feas,
        "total_cost": round(curr_cost, 2),
        "expected_value": round(curr_val, 2),
        "ranked_initiatives": ranked
    }
```

## Anti-Patterns & Guardrails

- **Over-Committing Beyond Resource Ceilings** — Recommending strategic portfolios whose combined budget exceeds $B_{\text{max}}$ without SMT verification.
- **Ignoring Project Dependencies** — Treating prerequisite initiatives independently, scheduling child projects before parent foundations are funded.
- **Zero Cost Division Errors** — Dividing by cost without bounding minimum expenditure ($C_i > 0$), resulting in infinite benefit-cost ratios.
